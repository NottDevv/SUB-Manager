## ✨ معرفی
پنل **SubManager Pro** یک اپلیکیشن کاملاً مستقل، سریع و بدون نیاز به سرور (Serverless) است که به شما اجازه می‌دهد تا کاربران و کانفیگ‌های VPN (لینک‌های vless, vmess, trojan و...) خود را به زیباترین و راحت‌ترین شکل ممکن مدیریت کنید.

این پروژه شامل یک پنل **فرانت‌اند فوق‌مدرن (React + Tailwind CSS)** است که مستقیماً در قالب یک **Cloudflare Worker** به صورت یکپارچه (Single-File) اجرا می‌شود. بدون نیاز به تهیه هاست و سرورهای گران‌قیمت، می‌توانید تمام اشتراک‌های خود را مدیریت کنید! 🚀

---

## 🔥 امکانات برجسته (Features)

- 🎨 **رابط کاربری بی‌نظیر (UI/UX):** طراحی مدرن با گرافیک جذاب (تم Slate & Emerald) و کاملاً واکنش‌گرا (Responsive) برای موبایل و دسکتاپ.
- 🌍 **پشتیبانی دو زبانه (فارسی و انگلیسی):** تغییر زبان سیستم به صورت در لحظه با تقویم شمسی و میلادی.
- ⚡ **مدیریت کاربران و لینک‌ها:** ساخت بینهایت کاربر، تعیین تاریخ انقضا، فعال/غیرفعال‌سازی اکانت‌ها با یک کلیک.
- 📱 **پورتال اختصاصی کلاینت‌ها (`/u/username`):** هر کاربر یک صفحه اختصاصی شیک دارد که می‌تواند کانفیگ‌های خود را مستقیماً با یک کلیک در **v2rayNG, Hiddify, Shadowrocket, NekoBox** ایمپورت کند یا QR Code آن‌ها را اسکن نماید.
- 🛡️ **امنیت بالا:** ورود با رمز عبور برای ادمین و کلاینت‌ها (اختیاری برای کلاینت‌ها).
- 💾 **سیستم پشتیبان‌گیری (Backup):** بکاپ‌گیری کامل از دیتابیس D1 با فرمت JSON با یک کلیک و قابلیت بازگردانی آن به سادگی هرچه تمام‌تر.
- ☁️ **بدون نیاز به سرور (Serverless):** اجرا ۱۰۰٪ روی شبکه جهانی Cloudflare با آپتایم ۱۰۰٪.

پنل مدیریت ساب‌منیجر به دو بخش تقسیم می‌شود. شما برای اجرای آن راه‌های مختلفی دارید.

### 🖥️ روش دوم: استقرار روی هاست اشتراکی (مانند cPanel یا دایرکت‌ادمین)
در این روش، شما باید فایل‌های ساخته‌شده (Build) رابط کاربری را روی هاست خود قرار دهید.

> **💡 نکته طلایی برای کاربران مبتدی (بدون نیاز به ساخت Build توسط خودتان):**
> برای راحتی شما، فایل‌های نهایی و آماده‌ی استقرار در پوشه `dist` (و در بخش Releases گیت‌هاب) قرار داده شده‌اند. نیازی نیست شما کدی را کامپایل کنید!

1. وارد پنل مدیریت هاست خود (cPanel / DirectAdmin) شوید.
2. به بخش **File Manager** بروید.
3. پوشه `public_html` را باز کنید (و اگر فایلی درون آن است، آن را خالی کنید).
4. محتویات درون پوشه `dist/` در این مخزن گیت‌هاب را دانلود کرده و مستقیماً داخل پوشه `public_html` آپلود کنید.
5. آدرس سایت خود را در مرورگر باز کنید. به همین راحتی! 🎉

---

### 💻 روش سوم: استقرار برای توسعه‌دهندگان (با استفاده از SSH / سرور مجازی)
اگر برنامه‌نویس هستید یا یک سرور مجازی (VPS) اوبونتو دارید و می‌خواهید کدهای پروژه را خودتان کامپایل کنید، مراحل زیر را طی کنید:

1. ابتدا سورس‌کد را روی سرور کلون کنید:
   ```bash
   git clone https://github.com/YourUsername/SubManager-Pro.git
   cd SubManager-Pro
   ```
2. پکیج‌ها و پیش‌نیازهای پروژه را نصب کنید:
   ```bash
   npm install
   ```
3. کدهای فرانت‌اند (React) را بیلد بگیرید:
   ```bash
   npm run build
   ```
4. با اجرای این دستور، پوشه‌ای به نام `dist` ساخته می‌شود. محتویات این پوشه را به ریشه (Root) وب‌سرور خود (مثلاً مسیر `/var/www/html/` برای Nginx یا Apache) منتقل کنید:
   ```bash
   cp -r dist/* /var/www/html/
   ```
